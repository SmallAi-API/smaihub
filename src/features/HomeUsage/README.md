# 首页个人用量与额度

个人首页当前助理使用 `smai`、服务商运行时配置已加载且有一个用户填写的 Key 时，启用已有首页 usage 插槽。工作区、未登录、空 Key、多 Key、其他服务商和查询失败时不渲染卡片。失败不解释为余额零；不限额 Key 不显示有限进度。

请求链路：`HomeUsageWidget → useSmaiUsage → aiProviderService.getSmaiUsage → aiProvider.getSmaiUsage → SmaiUsageService`。服务器只读取该用户个人服务商的解密凭据，不回退部署环境 Key，也不接受客户端传入上游地址或 Key。受限的模型读取 API Key 不能查询个人额度。请求使用 SSRF 安全 fetch、8 秒超时、禁止重定向，只按 HTTP 200 且 `code === true` 处理成功。

## 刷新与缓存

- 首次符合条件进入首页异步读取；首次响应前显示与额度、话题统计布局一致的骨架，失败仍隐藏卡片。返回首页或聚焦时，快照超过 30 秒或有消费事件则补查。
- 可见首页每 120–135 秒轮询，加入少量抖动。离开首页、隐藏卡片、页面后台、离线时停止。
- 对话、图片和视频终态只发送失效事件；合并延迟 6 秒，实际请求统一受至少 15 秒冷却与并发去重约束。冷却从成功响应返回后计算，避免再次命中旧快照。不会按流式 chunk 查询或推算余额。
- 客户端 SWR 快照和调度预算只在内存中，不持久化；账号、Key 或地址改变立即更换不含密钥的缓存身份。同一凭据的配置重新加载不重置预算。
- 服务器成功额度缓存 15 秒，换算配置按地址缓存 15 分钟，同身份并发合并。额度缓存按用户、规范化地址、Key 的 HMAC 隔离，缓存有容量上限。这是每个服务进程的缓存，不保证跨实例去重。
- 401/403 暂停自动重试，修改配置后恢复；429 遵守 `Retry-After`；临时失败指数退避 30–120 秒。确认失败后隐藏卡片，下一次成功重新出现。

## 数据口径

额度行显示当前 Key 的剩余 / 总额和剩余进度条；例如已用 $199.71、剩余 $100.00、总额 $299.71 时，显示 `$100.00 / $299.71`，进度约 33%。不限额显示 ♾️ 并隐藏有限额度进度。Key 提示只由服务端生成，格式为 `sk-124****123`，短 Key 完全隐藏，原始 Key 不进入额度响应、缓存值或 DOM。剩余和已用仅来自当前 Key，不合并可选 `user_quota` 钱包或订阅额度。金额按站点实际 `/api/status` 的 `quota_per_unit`、展示类型和汇率计算；无法取得有效换算时明确显示计费额度。极小金额保留不等式及精确值提示。下方 “话题” 区域直接复用个人统计组件，使用助理、话题、消息计数，详情链接到 `/settings/stats`；更新时间和刷新按钮位于卡片标题右侧。

此安全保证仅针对新增额度接口和卡片。项目既有服务商运行时、设置详情和 Desktop 绑定接口会向有权限的调用者返回解密凭据；客户端直连模型模式也需要浏览器持有 Key。因此不能把卡片脱敏宣称为整个应用在 F12 中无法取回 Key。若需要已保存凭据始终留在服务端，必须同步调整这些接口、执行模式判定和设置的凭据替换流程。

## 网关配套

`D:/new-api-main` 的 `/api/usage/token/` 已改用认证后独立的 `token_id` 限流：默认 6 次 / 60 秒，可用 `TOKEN_USAGE_RATE_LIMIT_ENABLE`、`TOKEN_USAGE_RATE_LIMIT`、`TOKEN_USAGE_RATE_LIMIT_DURATION` 配置。保留全局 API/IP 限流，不消耗共享 CriticalRateLimit 桶。上线需同时发布此网关改动；只发布前端仍可能触发旧的共享 IP 查询限制。
